Get a Live URL on your Phone in 60 Seconds

FinTrack Pro is 100% static and requires zero build steps. Deploy it for free on Vercel or GitHub Pages!

▲ Option A: Vercel (Fastest - 30 seconds) 100% Free
  1. Go to vercel.com/new and sign in.
  2. Drag & drop the folder D:\Myself\Money Manager or link your GitHub repo.
  3. Click Deploy. Vercel provides a free live HTTPS URL (e.g. fintrack.vercel.app) that you can open on your phone immediately!
🐙 Option B: GitHub Pages Built-in Actions

We've generated the complete .github/workflows/deploy.yml workflow. Simply push this folder to your GitHub repo, and GitHub Pages will deploy it automatically!

📲

Turn it into a Phone App (PWA):

Once you open your live URL on Safari (iPhone) or Chrome (Android), tap Share / Menu → "Add to Home Screen". It will look and launch just like a native mobile app!
